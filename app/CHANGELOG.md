# Android App Changelog

## Development milestone — 2026-08-27

این فایل تغییرات مهم اپ Android را ثبت می‌کند تا در انتشارهای بعدی مشخص باشد هر Build چه قابلیت‌هایی داشته است.

### مدیریت فروشگاه

- صفحه مدیریت دسته‌بندی‌ها با ساخت، ویرایش، ترتیب نمایش، فعال/غیرفعال و حذف.
- صفحه مدیریت کامل محصولات با نمایش دسته‌بندی هر محصول.
- ساخت محصول با انتخاب دسته‌بندی اختیاری.
- ویرایش نام، قیمت، توضیحات و دسته‌بندی محصول.
- فعال/غیرفعال کردن سریع محصول.
- حذف محصول فقط پس از تأیید کاربر.
- همگام‌سازی دسته‌بندی‌ها هنگام ورود به صفحه محصولات.

### کنترل کیفیت

- Android CI باید Unit Test و `assembleDebug` را با موفقیت اجرا کند.
- APK فقط بعد از موفقیت CI به‌عنوان فایل تست تحویل داده می‌شود.
- Backend CI شامل Syntax Check، تست‌های امنیتی و Cloudflare dry-run است.

> این Build هنوز Debug است. نسخه Release نهایی باید با کلید امضای ثابت پروژه ساخته شود تا آپدیت‌های بعدی روی نسخه نصب‌شده قابل نصب باشند.
